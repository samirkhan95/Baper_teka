# Contributing to Baper Teka 💰

Thank you for inspecting this repository! **Baper Teka** is maintained as a professional showcase repository by [@samirkhan95](https://github.com/samirkhan95).

## How to Contribute

1. **Bug Reports & Feature Requests**:
   - Feel free to open an issue via [GitHub Issues](https://github.com/samirkhan95/Baper_teka/issues).
   - Please provide a clear description of the issue, steps to reproduce, device model, and Flutter version.

2. **Pull Requests**:
   - Fork the repository and create your feature branch: `git checkout -b feature/amazing-feature`.
   - Ensure all Flutter unit and widget tests pass: `flutter test`.
   - Ensure clean code formatting and linting: `flutter analyze`.
   - Commit your changes with clear messages and push to your fork.
   - Submit a Pull Request targeting the `main` branch.

## Code Conventions
- Follow official [Effective Dart](https://dart.dev/guides/language/effective-dart) guidelines.
- Maintain architecture consistency (Provider for state management, SQLite for database, pure utility classes for business logic, and modular UI components).

Thank you for your interest and support!
